Пользовательское руководство по игре тараканьи бега

При запуске, нас встречает форма на которой изображены 2 таракана, которые будут участвовать в забеге 
<img width="1365" height="477" alt="image" src="https://github.com/user-attachments/assets/d8beaba4-9222-40e8-8d0c-69e22f3fefab" />

Сразу на кнопку старт нажать не получиться, высветиться ошибка в которой будет указано что нужно ввести имена тараканам, без введённых имём забег не начнётся
<img width="1361" height="468" alt="image" src="https://github.com/user-attachments/assets/072736d8-dba7-4634-b076-43b6d7981299" />

После ввода имён необходимо нажать на кнопку старт и тараканы побегут

<img width="1374" height="467" alt="image" src="https://github.com/user-attachments/assets/e5f4c708-d82b-41d0-892b-4c0640e4bce6" />

В конце забега программа выдаёт победителя забега 
<img width="1369" height="481" alt="image" src="https://github.com/user-attachments/assets/5a9f701e-ae5b-4fc0-9ddd-ab91bb258781" />

После забега можно устроить ещё 1 нажав на кнопку сброс, при этом имена сохранятся, которые вы вводили раннее!
<img width="1366" height="467" alt="image" src="https://github.com/user-attachments/assets/0e4aedcf-b68a-467d-9ca8-cc13a0b1a34d" />
